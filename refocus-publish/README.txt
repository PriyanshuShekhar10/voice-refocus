Voice Refocus — Chrome extension (store package)

Upload to Chrome Web Store:
1. Use ../refocus-chrome-store.zip
2. Developer Dashboard → New item → upload the zip
3. Paste STORE_LISTING.txt into the listing fields
4. Official URL: https://voice.refocus.co.in
5. Privacy policy URL: https://voice.refocus.co.in/privacy.html
6. Submit for review

Load unpacked for testing:
chrome://extensions → Developer mode → Load unpacked → select this folder
